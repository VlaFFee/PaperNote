# Paper Note (Minecraft 1.20.1, Forge 47.2.0+)

Креативный предмет «Записка». ПКМ открывает листок бумаги (с небольшой анимацией разворачивания),
на котором есть текст и фотография.

- Редактировать записку (писать текст, менять фото) может **только игрок в творческом режиме**.
  Остальные игроки могут её лишь читать. Права проверяются на сервере.
- Предмет лежит во вкладке творческого инвентаря «Записки».
- Мод нужно ставить и на клиент, и на сервер.

## Фотографии
Папка `papernote_photos` создаётся в папке игры автоматически при запуске, там же лежит `README.txt`.
При запуске мод проверяет папку и пишет в лог, сколько фото нашёл.

Как вставить фото: в творческом режиме откройте записку → **Фото** → кликните нужную картинку в сетке превью.
Можно просто перетащить файл (png, jpg, jpeg, gif, bmp) в окно игры — он скопируется в папку и вставится сразу.

Фото уменьшается (до 384 px) и сжимается в JPEG, после чего уходит на сервер и хранится в мире
(`<мир>/papernote_photos/`). Другие игроки получают его с сервера один раз и кэшируют
на диске (`<папка игры>/papernote_cache`, до ~64 МБ).

## Сборка через GitHub
1. Создайте репозиторий на github.com и загрузите **содержимое** папки проекта (включая `.github`).
2. Вкладка **Actions** → дождитесь зелёной галочки у "Build mod".
3. В завершённом запуске внизу (Artifacts) скачайте `papernote-jar`, внутри `papernote-1.20.1-1.0.0.jar`.
   Положите его в `mods`.

## Оптимизация
- превью и фото грузятся лениво, в отдельных потоках, большие фото читаются с прореживанием;
- лимит текстур в памяти (LRU): 10 фото и 80 превью, остальное выгружается;
- дисковый кэш с автоочисткой, сеть: куски по 28 КБ, лимиты размера и частоты запросов на сервере;
- перенос строк в тексте пересчитывается только при изменении.
